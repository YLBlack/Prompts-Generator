# ⚡ Expert Coding Prompt Generator

> A zero-dependency, single-file web application that transforms project briefs and raw technical requirements into highly structured, context-aware prompts for AI coding agents and CLI assistants.

🌟 Overview
---
The Expert Coding Prompt Generator helps developers write complete, rigorous system prompts for AI programming tools (such as Claude Code, Codex, Cursor, and Gemini CLI). Instead of writing loose or ambiguous instructions, this tool automatically structures your project state, constraints, technical debt, and priorities into a clean execution framework.

It runs 100% in the browser—no server, no tracking, and no external AI API calls needed to structure your prompts.

✨ Features:
---
🤖 Target Agent Tailoring: Automatically adjusts generated prompts for specific workflows (Claude Code, Codex, Cursor, Gemini CLI, or generic LLMs).

🎯 Task Type Auto-Detection: Analyzes your input to detect the task focus (Bug Fix, Refactoring, Automation/Scraping, Security Audit, etc.) and auto-selects execution rules.

📦 Quick-Packs: One-click requirement modules for common developer tasks (Proxy rotation, Anti-bot/Rate limiting, Exponential backoff, Resource leak prevention).

📐 Dynamic Complexity Engine: Scales the depth of instructions (Simple, Standard, Complex) based on your project requirements and context length.

📁 Form Templates & History: Save form configurations locally, export/import templates as JSON, and maintain a history of recently generated prompts.

🌐 Multilingual & Themes: Full support for Arabic and English UI with right-to-left (RTL) layout, custom section heading languages, and Dark/Light modes.

👁️ Live Preview & Formats: Export prompts in Markdown, Plain Text, or XML tags with a live rendered Markdown preview.

🚀 Quick Start
---
Fill in your project context and objective.

Click Generate Prompt and copy the output directly to your coding assistant.

🛠️ Stack & Implementation
---
Tech Stack: Single-file HTML5, CSS3 (CSS Variables, Grid/Flexbox), and Pure Vanilla JavaScript (ES6+).

Storage: Utilizes localStorage for automatic draft saving, template management, and local generation history.

Design: Dark minimalist theme inspired by modern developer tooling, with full support for Arabic typography (Cairo font).
