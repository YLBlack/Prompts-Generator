Turn a project brief into a structured prompt for coding agents — Claude Code, Codex, Gemini CLI, and others.

Quick-Packs — one-click requirement snippets that appear for Automation/Scraping tasks (proxy handling, retries, rate limits...).
Complexity — controls how much detail the generated prompt includes. Auto sizes it to your inputs; you can force Simple/Standard/Complex instead.
Target agent — adds a short note tailored to the coding agent you're using (Claude Code, Codex, Cursor...).
Diffs only — asks the agent to prefer targeted patches over rewriting whole files.
Output format — Markdown, plain text, or XML tags (XML is auto-suggested for Claude Code).
History — every prompt you generate is saved locally; similar past tasks are suggested for reuse.
