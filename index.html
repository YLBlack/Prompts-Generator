Expert Coding Prompt Generator

Turn a project brief into a structured prompt for coding agents — Claude Code, Codex, Gemini CLI, and others.

Templates — save the whole form under a name and reload it later. Your last draft is also restored automatically.
Task type — pick one or more manually, or leave it blank and the generator will guess from what you wrote (shown as a hint with a confidence level).
Quick-Packs — one-click requirement snippets that appear for Automation/Scraping tasks (proxy handling, retries, rate limits...).
Complexity — controls how much detail the generated prompt includes. Auto sizes it to your inputs; you can force Simple/Standard/Complex instead.
Target agent — adds a short note tailored to the coding agent you're using (Claude Code, Codex, Cursor...).
Diffs only — asks the agent to prefer targeted patches over rewriting whole files.
Output format — Markdown, plain text, or XML tags (XML is auto-suggested for Claude Code).
Key files — list the files the agent should read first; it anchors the prompt to your actual code.
Reference files — for material the agent can't reach in the repo (exported data, production logs, specs). Repo files belong in Key files; the agent reads those itself.
Share as link — encodes the whole brief into the URL so a teammate opens the exact same form. Nothing is uploaded; the link carries the data.
Reply language — asks the agent to write its summary in Arabic or English (code stays in its original language).
Agent cheatsheet
  • Claude Code — strongest with XML-tagged prompts (auto-selected) and explicit Validation + Definition of Done sections; follows AGENTS/CLAUDE.md conventions and keeps diffs tight when told to.
  • Codex — best with a compact brief and a clear root-cause flow; respond well to “investigate before acting” and verification commands it can run in the shell.
  • Cursor — strongest at multi-file UI-adjacent edits; benefits from listed key files and constraints that name what must not change.
  • Gemini CLI — good with plan-first prompts; asks it to explain the plan briefly, then execute with concrete edits and run the project's own checks.
  • Any agent — the generic opener keeps the prompt tool-neutral; pick a specific agent when you want its working-style notes appended.
History — every prompt you generate is saved locally; similar past tasks are suggested for reuse.
